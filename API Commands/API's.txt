# ZORO Admin Backend APIs

## Base URL

```text
http://localhost:8000
```

> Replace with your deployed/ngrok URL when not running locally.

## Frontend Base URL Setup

```js
const API_BASE = "http://localhost:8000";
```

## Response Envelope

Every endpoint returns this shape:

```json
{
  "success": true,
  "data": { },
  "message": "OK"
}
```

Errors look like:

```json
{
  "success": false,
  "message": "Error description",
  "statusCode": 400,
  "errors": { }
}
```

# Auth

## 1 — Admin Login

**Method:** `POST`

```text
http://localhost:8000/api/v1/auth/login/
```

### Body
```json
{
  "email": "admin@zoro.finance",
  "password": "yourpassword"
}
```

### Response
```json
{
  "access": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",

    "name": "Admin User",
```

## 25 — Preview KYC Document (presigned URL)

**Method:** `GET`

```text
http://localhost:8000/api/v1/kyc/documents/:documentId/preview/
```

### Headers
```text
Authorization: Bearer <admin_token>
```

### Response
```json
{
  "success": true,
  "data": {
    "url": "https://zoro-kyc-docs.s3.ap-south-1.amazonaws.com/kyc/689d.../passport_scan.jpg?X-Amz-Signature=...",
    "expiresIn": 300
  },
  "message": "OK"
}
```

> Unlike the PayO-style static `/kyc-docs/filename` URLs, this backend never serves a permanent public link — every document view goes through this endpoint and returns a link that expires in 300 seconds.
