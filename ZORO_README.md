# ZORO — Premium Crypto & Finance Admin Dashboard

## 🚀 Getting Started

```bash
# Install dependencies (already done)
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📄 Pages

| Route | Page |
|-------|------|
| `/` | Dashboard (charts, stats, alerts) |
| `/users` | User Management (table + profile drawer) |
| `/kyc` | KYC Verification (document review) |
| `/wallets` | Wallet Management (balances, freeze) |
| `/transactions` | Transactions (table + detail drawer) |
| `/referrals` | Referral Leaderboard & Analytics |
| `/rewards` | Reward Programs & Distributions |
| `/reports` | Export Reports (CSV, Excel, PDF) |
| `/system-logs` | System Activity Timeline |
| `/settings` | Profile, Security, Roles, API Keys |

## 🎨 Tech Stack
- **Next.js 15** — App Router
- **Tailwind CSS** — Utility-first styling
- **Framer Motion** — Smooth animations
- **Recharts** — Premium data visualization
- **Lucide React** — Beautiful icons
- **next-themes** — Dark/Light mode

## 🌙 Theme
Toggle dark/light mode using the sun/moon icon in the top bar.
